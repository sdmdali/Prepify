# Prepify — frontend + Express backend

This repository contains the existing HTML/CSS/vanilla JavaScript frontend and the generated Node.js/Express/MySQL backend.

Start with `INTEGRATION_STATUS.md` for honest integration coverage, setup instructions, and known gaps. API reference: `backend/API_DOCUMENTATION.md`. Backend setup: `backend/README.md`.

**Do not treat this package as fully verified:** database migration, real server startup, and browser-to-backend end-to-end flows require testing on a machine with MySQL and npm registry access.
